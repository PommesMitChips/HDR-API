# Documentation

The [HDR API wiki](wiki/README.md) is the current usage and API reference. Start with [API boundaries](wiki/API-Boundaries.md), then choose the [PB guide](wiki/Programmable-Blocks.md) or [mod integration](wiki/Mod-Integration.md).

See [interactive artwork controls](wiki/Interactive-Controls.md) for retained line/polyline/rotation handles, two-way numeric values and the native persistent bundle viewer. Numeric source writes and cooperative mod input need no client plugin; native PB mouse input requires HDR Client Renderer 0.9.13+ and remains ALPHA with live acceptance unverified.
